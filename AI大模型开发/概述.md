## 机器学习概述（Machine Learning Overview）

# Machine Learning（机器学习）

- 概述（Overview）
  - AI、ML、DL
    - 人工智能（Artificial Intelligence，AI）：一种思想，让计算机更像人类
    - 机器学习（Machine Learning，ML）：让计算机自主学习规律，是通往 AI 的一种途径
    - 深度学习（Deep Learning，DL）：模拟人脑，神经网络（neural network）是 ML 的一种实现方法
  - AI 的三要素（three elements of AI）
    - 数据（data）：决定模型的上限（upper bound）
    - 算法（algorithm）
    - 算力（compute）
      - CPU（Central Processing Unit）
      - GPU（Graphics Processing Unit）
      - TPU（Tensor Processing Unit）
      - 昇腾（Ascend，华为 NPU）
  - 机器学习发展史（history of ML）
    - 1950 · 图灵（Alan Turing）
    - 1956 · 约翰·麦卡锡（John McCarthy），人工智能之父
    - 亚瑟·塞缪尔（Arthur Samuel），机器学习之父
    - 2012 · 辛顿（Geoffrey Hinton）、AlexNet
    - 2017 · 谷歌 Transformer 架构：编码器（encoder，理解）/ 解码器（decoder，生成）
    - 2018 · BERT（编码器）与 GPT（解码器）
    - 2022 · OpenAI 推出 ChatGPT 3.5
  - 常用术语（terminology）
    - 样本（sample）
      - 一条数据
      - 包含（components）
        - 特征（feature / attribute，属性）
        - 标签（label / target，目标值、预测值）
    - 数据集（dataset）
      - 多个样本
      - 划分（split）
        - 训练集（training set）：模型学习规律，特征 `X_train`、标签 `y_train`
        - 验证集（validation set）：调整超参数（hyperparameters，深度学习），特征 `X_val`、标签 `y_val`
        - 测试集（test set）：测试模型（深度学习）/ 模型评估（机器学习），特征 `X_test`、标签 `y_test`
        - 常见划分比例（common ratios）：8 : 1 : 1、7 : 1.5 : 1.5
  - 算法分类（types of ML algorithms）
    - 监督学习（supervised learning）：有 feature、有 label，按数据类型（data type）分
      - 线性（continuous）Regression（回归）
        - Linear Regression（线性回归）：案例——波士顿房价预测（Boston housing）
        - Polynomial Regression（多项式回归）
        - Ridge / Lasso Regression（岭回归 / Lasso 回归）
        - GBDT（Gradient Boosting Decision Tree）
        - XGBoost / LightGBM
      - 离散（discrete）→ Classification（分类）
        - Logistic Regression（逻辑回归）
        - Decision Tree（决策树）
        - Random Forest（随机森林）
        - KNN（K-Nearest Neighbors，K-近邻）：案例——鸢尾花分类（Iris）
        - Naive Bayes（朴素贝叶斯）
        - SVM（Support Vector Machine，支持向量机）
        - XGBoost / LightGBM
    - 无监督学习（unsupervised learning）：有 feature、无 label，利用样本相似性（similarity）聚类
      - 聚类（clustering）
        - K-means
        - Hierarchical Clustering（层次聚类）
        - DBSCAN（density-based clustering，基于密度）
      - 降维（dimensionality reduction）：PCA（Principal Component Analysis，主成分分析）
      - 关联规则（association rules）：Apriori
    - 半监督学习（semi-supervised learning）：有 feature、少 label，节省标注成本（labeling cost）
      - 自训练算法（self-training）
      - 标签传播（label propagation）
      - 半监督 SVM（semi-supervised SVM）
    - 强化学习（reinforcement learning）
      - 核心要素（core elements）
        - agent（智能体）
        - 环境（environment）
        - 行动（action）
        - 奖惩（reward）
      - Q-Learning
      - SARSA（State-Action-Reward-State-Action）
      - DQN（Deep Q-Network）
      - 策略梯度（policy gradient）
  - 建模流程（modeling pipeline）
    - 数据准备（data preparation）
    - 数据预处理（data preprocessing）
    - 特征工程（feature engineering）
      - 标准化（standardization）/ 归一化（normalization）
      - 解决量纲问题（unit scale mismatch）
    - 模型训练（model training）
    - 模型预测（prediction / inference）
    - 模型评估（model evaluation）
  - 特征工程（feature engineering）
    - 利用专业背景知识处理数据，让模型更好
    - 方式（methods）
      - 特征提取（feature extraction）
      - 特征预处理（feature preprocessing）
      - 特征选择（feature selection）
      - 特征降维（dimensionality reduction）
      - 特征组合（feature crossing）
  - 模型的拟合情况（model fit）
    - 欠拟合（underfitting）
    - 正好拟合（good fit）
    - 过拟合（overfitting）
  - 环境搭建（environment setup）
