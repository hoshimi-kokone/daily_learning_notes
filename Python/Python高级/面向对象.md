# 面向对象

## 面向对象基础

### 一、面向对象编程思想

#### 1、什么是面向过程(POP,Procedure-Oriented Programming)

传统的面向过程的编程思想总结起来就八个字 —— **自顶向下，逐步细化**。

先定义问题，在拆成若干步骤，每个步骤用函数/过程实现。数据和对数据的操作通常是分开的。

##### 优点：

- 思路直接，符合“按步骤办事”的直觉
- 对简单问题、算法问题、脚本任务效率高
- 函数调用清晰，性能开销通常较小
- 适合嵌入式、底层开发、数据处理流程等

##### 缺点

- 数据和对数据的操作分离，状态容易被多个函数随意修改
- 系统变大后，函数和全局数据增多，维护困难
- 需求变化时，流程改动可能牵连很多函数
- 复用多停留在“函数复用”，较难复用一整套状态和行为

#### 2、什么是面向对象(OOP, Object-Oriented Programming)

把系统中的事务抽象成 **对像** 。对像既有 **数据/状态** ，也有 **行为/方法** 。对像对外提供接口，内部细节隐藏起来；对象之间通过调用方法协作。

Python 的 OOP 有几个鲜明特点：**一切皆对象、动态类型、鸭子类型、支持多继承、没有真正的私有成员**

> 鸭子类型(Duck Typing):是动态类型语言里的一种类型观念：**如果它走起来像鸭子、叫起来像鸭子，那它就是鸭子**

##### 常见的四大特征

- **封装(Encapsulation)** ：把数据和操作数据的方法放在一起，隐藏内部细节。
- **抽象(Abstraction)** ：只暴露关键特征，忽略无关细节
- **继承(Inheritance)** ：复用和扩展已有类型。注意继承不是唯一复用方式，组合往往更常用。
- **多态(Polymorphism)** ：同一接口，不同对象有不同实现。

##### 优点

- 模块边界清晰，适合复杂业务建模
- 封装降低耦合，内部变化对外影响小
- 易扩展：新增类型或行为时，往往只需增加类，少改代码
- 易维护、易复用、易团队协作
- 多态适合处理 “同一类问题有不同实现” 的场景

##### 缺点

- 设计成本高，需要抽象能力
- 容易过度设计：类太多、层次太深、为了模式而模式
- 对象创建、间接调用可能带来一定性能和管理开销
- 简单问题上用 OOP 可能显得笨重

#### 对比

面向过程：关注 **怎么做** ，按步骤解决问题；
面向对象：关注 **谁来做** ，把数据和行为打包成事物。

| 维度 | 面向过程 | 面向对象 |
|---|---|---|
| 关注点 | 步骤、流程、算法 | 对象、职责、协作 |
| 基本单位 | 函数/过程 | 类/对象 |
| 数据与行为 | 通常分离 | 封装在一起 |
| 扩展方式 | 增加/修改函数和流程 | 增加对象/类，调整协作 |
| 适合场景 | 简单任务、算法密集、流程固定 | 复杂业务、需求多变、多人协作 |
| 典型问题 | 数据散落、状态难控 | 抽象过度、设计复杂 |

> 面向过程(POP)和面向对象(OOP)不是绝对对立的
> 面向过程适合组织“步骤”，面向对象适合组织“职责和协作”。
> 实际开发中常常是：**宏观用对象划分模块，微观用过程实现算法**

### 二、类(class)

类：是对一类事物的抽象模板，包含 **属性** 和 **方法/行为** .

#### 1、最基础的类

`__init__` 是 **构造方法**：创建对象的时候自动调用，用来初始化属性
`self` 代表当前这个实例本身，必须写在实例方法第一个参数

```python
# 定义一个类
class Dog:
    # 构造函数:初始化属性
    def __init__(self, name, age):
        self.name = name   # 实例属性
        self.age = age
    # 实例方法
    def bark(self):
        return f'{self.name} 汪汪叫'

# 根据类，创建实例(对象)
d = Dog('旺财', 3)

# 调用属性、方法
print(d.bark())  # 旺财 汪汪叫
print(d.name, d.age)  # 旺财 3
```

#### 2、实例属性 vs 类属性

```python
class Dog:
    species = '犬科'  # 类属性，所有实例共享
    # 可以直接使用类调用, Dog.species
    # 通常我们调用类属性只允许通过类名调用

    def __init__(self, name):
        self.name = name  # 实例属性，每个实例独立

d1 = Dog('旺财')
d2 = Dog('小黑')

print(d1.species, d2.species)  # 犬科 犬科
print(d1.name, d2.name)  # 旺财 小黑

Dog.species = 'Canidae'
print(d1.species)  # Canidae

d1.name = '大黄'
print(d2.name)  # 小黑，不受影响
```

##### 区别

|  | 实例属性 | 类属性 |
|---|---|---|
| 定义位置 | `__init__` 里的 `self.x` | 类体里直接定义 |
| 归属 | 每个实例独立，实例级 | 所有实例共享，类级 |
| 修改影响 | 只影响该实例 | 影响所有未覆盖的实例 |

#### 3、三种方法

```python
class Circle:
    pi = 3.14159
    
    def __init__(self, r):
        self.r = r
    
    # 实例方法：第一个参数是 self，实例本身,实例本身，行业约定俗成实力本身为 self
    def area(self):
        return self.pi * self.r**2
    
    # 类方法：第一个参数是 cls，类本身,行业约定俗成类本身为 cls
    @classmethod
    def from_diameter(cls, d):
        return cls(d/2) # 返回类(d/2),相当于实例化一个Circle类,Circle(d/2)
    
    # 静态方法：没有 self/cls
    @staticmethod
    def is_valid_radius(r):
        return r > 0

# 用类方法当 “备用构造器”
c = Circle.from_diameter(4)
print(c.area()) # 12.56636
print(Circle.is_valid_radius(3)) # True
```

| 方法类型 | 第一个参数 | 用途 |
|---|---|---|
| 实例方法 | `self` | 操作实例属性，必须要有对象才能调用 |
| 类方法 | `cls` | 操作类状态、构造器工厂、继承友好 |
| 静态方法 | 无 | 与类逻辑相关但不需要实例/类状态的工具函数 |

#### 4、封装：私有属性与 Property

Python中 **没有真正的私有**，靠命名约定

- `_x`:约定内部使用(单下划线)，软私有
  - 只是给程序员看的提示：这个属性尽量不要在类外面直接访问
  - **语法上完全能访问，没有任何限制**
  ```python
    class A:
        def __init__(self):
            self.x = 10
    a = A()
    print(a._x) # 可以正常读出 10，只是规范上不建议你这么写
  ```
- `__x`:双下划线开头，Python会自动把名字重命名：`__x` -> `_类名__x`
  - 目的：**防止子类不小心把父类的这个属性覆盖掉，不是用来做严格私有！**
  - 很多人认为 `__x` 是私有不让访问，其实只是改了名字，绕一下依然能访问
  ```python
    class A:
        def __init__(self):
            self.x = 10
    a = A()
    # print(a.__x) # 直接访问 __x 会报错
    print(a._A__x) # 改名之后真实名字，照样可以拿到！输出10
  ```
- `__x__`:双下划线首尾，是特殊方法/魔法方法，是Python内置预留的，**不要自己随便定义这种名字**
  - 比如：
    - `__init__`
    - `__str__`
    - `__len__`

##### 魔法函数(Magic Methods/Dunder Methods)

魔法函数就是名字前后各带两个下划线的方法，如`__init__`、`__add__`、`__len__`。它们让自定义对象能接入 Python 的 内置于法和协议，是 Python 面向对象和数据模型的核心。

###### (1) 、核心机制：隐式调用

魔法函数 **不是给你直接调用的** ，而是由 Python 解释器在特定于法场景下自动触发：

```python
len(obj)        # → obj.__len__()
obj + other     # → obj.__add__(other)
obj[i]          # → obj.__getitem__(i)
with obj: ...   # → obj.__enter__() / obj.__exit__()
print(obj)      # → obj.__str__()
obj()           # → obj.__call__()
```

设计哲学：

- **语法即协议**：你实现魔法方法，对象就 “会” 这个操作。
- **不要直接调用**：写 `obj.__len__()` 通常不对，应写 `len(obj)`
- **协议驱动**：Python 的大量内置功能(迭代、切片、上下文管理、格式化)都靠魔法方法对接

###### (2)、按类别详解

1. 对象声明周期
```python
class Foo:
    def __new__(cls, *args, **kwargs):    # 真正创建实例
        print("__new__")
        return super().__new__(cls)

    def __init__(self, x):                # 初始化实例
        print("__init__")
        self.x = x

    def __del__(self):                    # 对象被销毁时（不保证时机）
        print("__del__")

f = Foo(1)
# __new__
# __init__
```
| 方法 | 触发 | 说明 |
|---|---|---|
| `__new__` | 创建实例时 | 静态方法，必须返回实例；常用于单例、不可变类型子类化 |
| `__init__` | 实例创建后 | 初始化，返回值必须为 `None` |
| `__del__` | 引用计数归零 / GC | **不要依赖它做重要清理**， 用 `with` / `try_finally` 更可靠 |

```python
# 单例模式
class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```

2. 字符串表示

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __repr__(self):
        return f"Point({self.x!r}, {self.y!r})"   # 调试用

    def __str__(self):
        return f"({self.x}, {self.y})"            # 用户用

    def __format__(self, spec):
        if spec == "xy":
            return f"{self.x},{self.y}"
        return str(self)

p = Point(1, 2)
print(repr(p))        # Point(1, 2)
print(str(p))         # (1, 2)
print(f"{p}")         # (1, 2)
print(f"{p:xy}")      # 1,2
```

| 方法 | 触发 |
|---|---|
| `__repr__` | `repr()`、交互式回显、容器打印内部元素 |
| `__str__` | `str()`、`print()`、f-string；**未定义时回退到**  `__repr__` | 
| `__format__` | `format()`、f-string 带格式说明符 |
| `__bytes__` | `bytes(obj)` |

> `__repr__` 最好能 “重建” 对象，至少信息完整；
> `__str__` 面向用户可读。
> 至少实现 `__repr__`

3. 比较与哈希

```python
from functools import total_ordering

@total_ordering
class Version:
    def __init__(self, major, minor):
        self.major, self.minor = major, minor

    def __eq__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return (self.major, self.minor) == (other.major, other.minor)

    def __lt__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return (self.major, self.minor) < (other.major, other.minor)

    def __hash__(self):
        return hash((self.major, self.minor))

v1, v2 = Version(1, 2), Version(1, 3)
print(v1 < v2, v1 == v2)        # True False
print({v1, v2})                 # 可哈希
```

| 方法 | 触发 |
|---|---|
| `__eq__`/`__ne__` | `==`/`!=` |
| `__lt__` `__le__` `__gt__` `__ge__` | `<` `<=` `>` `>=` |
| `__hash__` | `hash()`、`set`/`dict` 的key
| `__bool__` | `bool()`、`if obj：` ; 未定义时回退 `__len__` |

**关键规则**：

- 定义 `__eq__` 而未定义 `__hash__`，实例会变成不可哈希（`__hash__ = None`），不能放入 `set` 或作 `dict` key。
- 比较方法遇到不认识类型应返回 `NotImplemented`（不是 `False`），`Python` 会尝试反向比较。
- `functools.total_ordering` 只需实现 `__eq__` + 一个排序方法，自动补齐其余比较。

4. 数值运算

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):          # v1 + v2
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __radd__(self, other):         # other + v1（other 不支持时）
        return self.__add__(other)

    def __iadd__(self, other):         # v1 += v2（就地修改）
        self.x += other.x
        self.y += other.y
        return self

    def __mul__(self, k):              # v * 3
        return Vector(self.x * k, self.y * k)

    def __rmul__(self, k):             # 3 * v
        return self.__mul__(k)

    def __neg__(self):                 # -v
        return Vector(-self.x, -self.y)

    def __abs__(self):                 # abs(v)
        return (self.x ** 2 + self.y ** 2) ** 0.5

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v = Vector(1, 2)
print(v + Vector(3, 4))    # Vector(4, 6)
print(3 * v)               # Vector(3, 6)
print(-v)                  # Vector(-1, -2)
print(abs(v))              # 2.236...
```

**三类运算方法**：

| 类别 | 前缀 | 例子 | 说明 |
|---|---|---|---|
| 普通 | `__add__` | `a + b` | 左操作数方法 |
| 反向 | `__radd__` | `b + a` | 左操作数返回 `NotImplemented` 时调用右操作数 |
| 就地 | `__iadd__` | `a += b` | 未定义时回退到 `__add__` 再赋值 |

**常用算数方法一览**：

| 运算符 | 普通 | 反向 | 就地 |
|---|---|---|---|
| `+` | `__add__` | `__radd__` | `__iadd__` |
| `-` | `__sub__` | `__rsub__` | `__isub__` | 
| `*` | `__mul__` | `__rmul__` | `__imul__` |
| `/` | `__truediv__` | `__rtruediv__` | `__itruediv__` | 
| `//` | `__floordiv__` | `__rfloordiv__` | `__ifloordiv__` |
| `%` | `__mod__` | `__rmod__` | `__imod__` |
| `**` | `__pow__` | `__rpow__` | `__ipow__` |
| `@` | `__matmul__` | `__rmatmul__` | `__imatmul__` |
| `&` `\|` `^` `<<` `>>` | `__and__` `__or__` `__xor__` `__lshift__` `__rshift__` | 加`r` | 加`i` |

**一元运算与数值转换**：

| 方法 | 触发 |
|---|---|
| `__neg__`/`__pos__`/`__abs__`/`__invert__` | `-x`/`+x`/`abs(x)`/`~x` |
| `__round__` | `round(x)` |
| `__trunc__` | `__floor__` | `__ceil__` | `math.trunc/floor/ceil(x)` |
| `__int__`/`__float__`/`__complex__` | `int(x)`/`float(x)`/`complex(x)` |
| `__index__` | 切片、`range()` 等需要整数处 |

5. 容器协议

```python
class MyList:
    def __init__(self, data):
        self._data = list(data)

    def __len__(self):                 # len(obj)
        return len(self._data)

    def __getitem__(self, i):          # obj[i]、切片、for 迭代回退
        return self._data[i]

    def __setitem__(self, i, v):       # obj[i] = v
        self._data[i] = v

    def __delitem__(self, i):          # del obj[i]
        del self._data[i]

    def __contains__(self, x):         # x in obj
        return x in self._data

    def __iter__(self):                # for x in obj
        return iter(self._data)

    def __reversed__(self):            # reversed(obj)
        return reversed(self._data)

    def __repr__(self):
        return f"MyList({self._data!r})"

ml = MyList([1, 2, 3])
print(len(ml), ml[0], 2 in ml, list(reversed(ml)))
ml[0] = 10
print(ml)
```

| 方法 | 触发 | 回退 |
|---|---|---|
| `__len__` | `len()` |  |
| `__getitem__` | `obj[i]`、切片 | 未定义 `__iter__` 时，`for` 会用它 |
| `__setitem__`/`__delitem__` | 赋值/删除 |  |
| `__contains__` | `in` | 未定义时用 `__iter__` 遍历 |
| `__iter__` | `for`、`iter()` |  |
| `__reversed__` | `reversed()` | 未定义时用 `__len__` + `__getitem__` |
| `__missing__` | dict 子类中 key 不存在 | 仅 `dict` 子类有效 |

##### `@property` 装饰器

作用：**把方法伪装成属性**，让你用 `obj.属性` 的方式调用，而不用写括号 `obj.方法()`

一般搭配上面的 `_x` 来用：让内部存 `_x` ，对外暴露 property 接口，控制读写、校验

**基础写法(只读)**

```python
class Circle:
    def __init__(self, r):
        self._r = r  # 内部私有存储，单下划线约定

    @property
    def r(self):
        # getter 获取器
        print("触发读取")
        return self._r

c = Circle(5)
print(c.r)   # 像访问属性一样，不是 c.r()
# c.r = 10  直接赋值会报错，只读
```

**搭配 setter(支持修改，还能做校验) 使用**

```python
class Circle:
    def __init__(self, r):
        self._r = r

    @property
    def r(self):
        return self._r

    @r.setter
    def r(self, value):
        # 赋值的时候自动走这里，可以加校验
        if value <= 0:
            raise ValueError("半径必须大于0！") # raise 抛出异常 “半径必须大于0！”
        self._r = value

c = Circle(5)
print(c.r)
c.r = 10   # 触发setter校验
# c.r = -3  会抛出异常
```

**deleter(删除)**

```python
    @r.deleter
    def r(self):
        del self._r
```

### 三、继承

#### 1、基本继承与方法重写

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

    def info(self):
        return f"我是 {self.name}，叫声：{self.speak()}"

class Dog(Animal):
    def speak(self):                    # 重写父类方法
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵喵"

d = Dog("旺财")
print(d.info())     # 我是 旺财，叫声：汪汪
```

`info()` 定义在父类，调用 `self.speak()` 时，**实际执行的是子类的实现** —— 这就是继承带来的多态

#### 2、super()与扩展父类行为

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)      # 调用父类 __init__
        self.breed = breed

    def info(self):
        base = super().info()       # 也可以调用父类方法
        return f"{base}，品种：{self.breed}"
```

`super()` 不是 “父类”，而是 **MRO中当前类的下一个类，在多继承里很重要**。

#### 3、多继承与 MRO

Python 支持多继承，方法解析顺序用 **C3线性化算法** ，通过 `类.__mro__` 查看：

```python
class A:
    def hi(self): print("A")

class B(A):
    def hi(self): print("B")

class C(A):
    def hi(self): print("C")

class D(B, C):
    pass

print(D.__mro__)
# (<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>)
D().hi()    # B
```

**规则要点**：

- 子类优先与父类
- 同层按声明顺序(`B`在`C`前)
- 所有类最终汇聚到`object`

**菱形继承** 下 `super()` 会沿着 MRO 链走，而不是简单 “调父类”：

```python
class A:
    def hi(self): print("A")

class B(A):
    def hi(self):
        print("B")
        super().hi()

class C(A):
    def hi(self):
        print("C")
        super().hi()

class D(B, C):
    def hi(self):
        print("D")
        super().hi()

D().hi()
# D → B → C → A
```

这是协作式多继承(cooperative multiple inheritance) 的典型模式。实际项目中 **多继承要慎用** ，能用组合(composition) 就别用多继承。

**组合**：

```python
class Engine:
    def run(self):
        print("发动机启动")

# 汽车【有一个】发动机，不是“汽车是发动机” → 用组合
class Car:
    def __init__(self):
        # 组合：Car里面持有Engine的实例
        self.engine = Engine()

    def start(self):
        self.engine.run()  # 调用里面对象的方法

c = Car()
c.start()
```

**聚合**：

```python
class Student:
    pass

class ClassRoom:
    def __init__(self, stu_list):
        self.stus = stu_list # 只是引用学生对象，学生独立存在
```

#### 4、`isinstance` 和 `issubclass`

- `isinstance(obj, cls)`：判断一个对象 `obj` 是不是 `cls` （或它子类）的实例，返回 `True` 或 `False`
  - 特点：
    - 会向上兼容子类(子类实例也算)
    - 第二个参数可以传元组：判断是不是其中任意一种类型
  ```python
    class A: pass
    class B(A): pass

    b = B()
    print(isinstance(b, B))  # True，b是B的实例
    print(isinstance(b, A))  # True，B继承A，b也是A子类的实例
    print(isinstance(b, (A, str))) # True，是A或者str吗？满足A
  
  ```
- `issubclass(sub, super)`：判断类 `sub` 是不是 `super` 的子类，返回 `True` 或 `False`
  - 特点：
    - 只接收类，不能传实例！
    - 第二个参数也支持元组
    - 自己本身也是自己的子类
  ```python
    print(issubclass(B, A)) # True，B是A的子类
    print(issubclass(B, B)) # True
    print(issubclass(A, B)) # False
  ```

#### 5、`object` 所有类的根

```python
class Foo:          # 等价于 class Foo(object):
    pass

print(Foo.__mro__)  # (<class 'Foo'>, <class 'object'>)
```

Python 3 中所有类都隐式继承 `object` ，`object` 提供 `__init__`、`__str__`、`__eq__`等基础方法。

### 四、多态

#### 1、什么是多态？

同一接口，不同对象有不同实现。调用方只关心“能做什么”，不关心“是什么”。

```python
class Animal:
    def speak(self): ...

class Dog(Animal):
    def speak(self): return "汪汪"

class Cat(Animal):
    def speak(self): return "喵喵"

def make_sound(animal: Animal):
    print(animal.speak())

for a in [Dog(), Cat()]:
    make_sound(a)
# 汪汪
# 喵喵
```

```make_sound``` 只依赖 `speak()` 这个接口，新增动物类型 **不需要改它** —— 这就是开闭原则的体现。

#### 2、鸭子类型：Python 的多态核心

> “如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子。”

Python 不检查类型，只检查方法是否存在：

```python
class Duck:
    def quack(self): return "嘎嘎"

class Person:
    def quack(self): return "我会学鸭子叫"

def do_quack(thing):
    print(thing.quack())     # 只要有 quack() 就行

do_quack(Duck())
do_quack(Person())           # 没有继承关系也没问题
```

- 好处：极度灵活，天然支持解耦
- 代价：错误只能在运行时暴露，IDE/静态检查帮助有限

#### 3、抽象基类：显式约定接口

如果想强制子类实现某些方法，用 `abc` 模块：

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self): ...

    @abstractmethod
    def perimeter(self): ...

class Circle(Shape):
    def __init__(self, r):
        self.r = r

    def area(self):
        return 3.14159 * self.r ** 2

    def perimeter(self):
        return 2 * 3.14159 * self.r

# s = Shape()       # TypeError: 不能实例化抽象类
c = Circle(2)
print(c.area())
```

`abc` 的定位：**介于纯鸭子类型和强类型约束之间的折中**

还可以用 `ABCMeta` 的 `register` 的虚拟子类，或者 `Shape.register(SomeClass)` ，让一个已有类“声明”实现了接口。

#### 4、Protocol：结构化类型(Python3.8+)

`typing.Protocol` 是给静态类型检查器用的“鸭子类型”声明：

```python
from typing import Protocol

class Quacker(Protocol):
    def quack(self) -> str: ...

def do_quack(q: Quacker) -> None:
    print(q.quack())

class Duck:
    def quack(self) -> str:
        return "嘎嘎"

do_quack(Duck())     # 类型检查通过：结构匹配即可
```

区别：
- `ABC` ：**运行时** 强制，必须继承
- `Protocol`：**静态检查时** 的结构化约定，不要求继承(但运行时不做检查)

#### 5、多态的三种形态对比

| 形态 | 机制 | 特点 |
|---|---|---|
| 继承重写 | 子类重写父类方法 | 经典 OOP，强依赖继承 |
| 鸭子类型 | 只依赖方法签名 | 最灵活，Python主流 |
| 抽象基类/Protocol | 显式或半显式接口约定 | 更易维护、利于静态检查 |

### 最佳实践

- **优先组合而非继承** ：`has-a`用组合, `is-a`采用继承
- **小的、职责单一的类** ：一个类只做一件事
- **用 `@property` 控制访问** ，而不是无脑暴露属性或大量 `getter/setter`
- **用 `__repr__` 便于调试** ，`__str__` 用于面向用户
- **接口用小而明确的抽象** ：一个抽象基类别塞太多抽象方法
- **`dataclass` 处理纯数据类**：减少模板代码。
  ```python
    from dataclasses import dataclass

    @dataclass
    class Point:
        x: float
        y: float
        z: float = 0.0

    p = Point(1, 2)
    print(p)        # Point(x=1, y=2, z=0.0)
    print(p == Point(1, 2))  # True（自动生成 __eq__）
  ```
