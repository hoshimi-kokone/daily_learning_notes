# ArrayList
自动扩容，只能装 **引用数据类型**

需要装基本数据类型必须把基本数据类型变成对应的包装类

```java
import java.util.ArrayList;

public class HelloWorld {
    static void main() {
        ArrayList<String> list = new ArrayList<>();

        // Create

        list.add("Hello");
        list.add("World");
        list.add("Hello");
        list.add("World");
        list.add("Hello");
        list.add("World");
        System.out.println(list);

        // read
        String s = list.get(0);
        System.out.println(s);

        System.out.println(list.size());  //长度

        // update
        String result = list.set(1, "add");  //返回被覆盖的元素
        System.out.println(result);


        // delete
        boolean result1 = list.remove("World");   //返回true  false
        System.out.println(result1);

        String result2 = list.remove(1);    //返回删除的元素
        System.out.println(result2);

    }
}

```
